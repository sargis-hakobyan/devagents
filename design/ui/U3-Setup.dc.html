docker compose exec -it devagents node dist/cli/main.js auth setup

How this shows up elsewhere
Overview · empty workspace "Nothing is running" becomes a setup card listing the unfinished steps with the same chips, and a single "Finish setup" link to this page. No invented readiness: the card disappears only when the service reports the steps done.
Submit work · missing connection The form stays usable with a warning banner ("will wait; planning fails until a sign-in is saved") so a user can queue work before finishing the terminal step. The resolved summary repeats the connection state.
Task failed at preflight The task header's failure note links here: "Failed before planning: Codex is not signed in. Finish setup, then submit a new task." Resubmission is a new task; the failed one keeps its history.
Change or replace the sign-inTerminal only in U3
Replacing a key or switching to ChatGPT uses the same terminal flow with --replace-key or --auth chatgpt. The browser shows the resulting state (method, store, locked/unlocked) and nothing else. A browser-based credential wizard is not part of this increment.
