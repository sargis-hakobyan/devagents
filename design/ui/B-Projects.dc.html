Diagnostics shown when a path fails
  • Not accessible — ENOENT or permission denied at the registered path; tasks stay readable, submissions blocked.
  • Moved — the canonical path changed since registration; re-register at the new location.
  • Not a Git root — the path is inside a repository; register the checkout root.
  • Docker UID — the container’s non-root UID 1000 cannot read the mount; adjust ownership/ACLs on the host.
